# Feature Specification: ページ番号の直接入力

**Created**: 2026-09-26

**Status**: Implemented

**Input**: しおりのない多数ページのPDFでもページ番号を直接入力して移動する。メイン画面と別ウィンドウの操作を揃える。

## User Scenarios & Testing

### User Story 1 - 指定ページへ移動する (P1)

利用者は上部の現在ページ番号をクリックし、1始まりのページ番号を入力してEnterで移動する。Ctrl+Gで入力欄にフォーカスできる。

**Acceptance Scenarios**:

1. 150ページのPDFで120を入力してEnterを押すと120ページに移動する。
2. しおりのないPDFでも同じ操作ができる。
3. メイン画面と別ウィンドウの両方で同じ操作ができる。

### User Story 2 - 入力を取り消す (P1)

Escまたはフォーカスを外すと編集を取り消し、現在ページ番号に戻す。

### User Story 3 - 入力を誤った場合 (P2)

数字以外、0、最終ページ超過では移動せず、許容範囲を案内する。

## Edge Cases

- PDF未表示または0ページの場合、入力欄は無効にする。
- 編集中にスクロールや前後ボタンでページが変わっても入力途中の数字は保持し、確定・取消後に現在ページを反映する。
- タブ切り替え時は新しいタブのページ番号と総ページ数を表示する。

## Requirements

- **FR-001**: 現在ページ番号を直接入力してEnterで移動できる。
- **FR-002**: Ctrl+Gで入力欄を選択できる。
- **FR-003**: Escとフォーカス離脱で入力を取り消せる。
- **FR-004**: 範囲外や不正な入力を拒否し、範囲を案内する。
- **FR-005**: ページ移動とタブ切り替えに表示が追従する。
- **FR-006**: 別ウィンドウでも同じ操作ができる。

## Success Criteria

- しおりのない150ページのPDFで120ページへ直接移動できる。
- 境界値1と150は成功し、0と151および数字以外は移動しない。
- メイン画面と別ウィンドウの操作確認が成功する。

## Assumptions

- 入力する番号はPDF全体の1始まりのページ番号。別ウィンドウでは抽出範囲内の1始まりの番号。
