# Implementation Plan: ページ番号の直接入力

## Context

`main.py` のメイン画面と `PageRangeWindow` は、ともにページ表示に `QLabel` を使用している。既存の前後ボタンは `QPdfView.pageNavigator().jump()` を使用する。

## Design

1. 共通のページ入力ウィジェットを `main.py` に追加する。入力欄と総ページ数表示、入力検証、取消、フォーカス操作をまとめる。
2. 両ツールバーのページラベルを置き換え、Enter時に1始まりの番号を0始まりへ変換して既存のページナビゲータへ渡す。
3. ページ変更、タブ切り替え、PDF未表示でウィジェットの表示と有効状態を同期する。Escは既存のメイン画面ショートカットと衝突しないよう入力編集中の取り消しを優先する。
4. 合成PDFで移動、境界値、無効入力、取消、別ウィンドウをGUIテストする。

## Data and compatibility

PDF、SQLite、設定ファイルには変更しない。前後ボタン、検索、しおり操作は従来のナビゲータを使う。
