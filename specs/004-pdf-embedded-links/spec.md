# Feature Specification: PDF埋め込みリンクの操作

**Created**: 2026-09-25
**Status**: Approved for implementation
**Input**: PDFに埋め込まれたリンクを動作させる。PDF内、Web、メール、`file:` リンクを含む。

## User Scenarios & Testing

### User Story 1 - PDF内の移動 (Priority: P1)

利用者はPDF上のページリンクをクリックし、指定されたページへ移動できる。

**Acceptance Scenarios**:

1. リンクのある位置をクリックすると、同じPDFの指定ページへ移動する。
2. リンク以外をクリックしてもページは変わらない。

### User Story 2 - 外部リンク (Priority: P1)

利用者はPDF上のWeb、メール、ファイルリンクをクリックし、対応する既定のアプリで開ける。

**Acceptance Scenarios**:

1. `http:` と `https:` は既定のブラウザーで開く。
2. `mailto:` は既定のメールアプリで開く。
3. `file:` の絶対パスとPDFのあるフォルダからの相対パスを既定のアプリで開く。
4. リンク先が存在しない場合、エラーを表示してPDF閲覧を継続する。
5. 日本語を含むネットワーク共有のファイルリンクは、文字化けしたパスを表示せず元のパスで開く。

### Edge Cases

- メール一覧としおり一覧の両方で同じ動作にする。
- 表示倍率、スクロール位置、ページ境界によらず正しいリンクだけが反応する。
- PDF本体とインデックスは変更しない。

## Requirements

- FR-001: PDF内のリンクをクリックで開く。
- FR-002: Web、メール、ファイルのリンクを対応する既定アプリへ渡す。
- FR-003: 相対ファイルリンクはPDFの親フォルダを基準に解決する。
- FR-004: 未対応のリンク形式を実行しない。
- FR-005: 既存のページ移動、検索、モード切り替えを維持する。

## Success Criteria

- SC-001: 合成PDFで４種類のリンクとページ移動がクリック１回で動作する。
- SC-002: リンク以外のクリックで外部アプリが開かない。
