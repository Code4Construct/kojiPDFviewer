# Feature Specification: 手動でしおり一覧へ切り替え

**Created**: 2026-09-25
**Status**: Approved for implementation
**Input**: メールモードで開いたPDFでも、一覧上部のボタンからしおり一覧へ強制的に切り替える。

## User Scenarios & Testing

### User Story 1 - メールからしおりへ (Priority: P1)

メール一覧でPDFを読んでいる利用者は、一覧上部右側の「しおり一覧へ」を押し、同じPDFをしおり階層で閲覧できる。

**Acceptance Scenarios**:

1. メール一覧で開いたPDFでボタンを押すと、同じタブがしおり一覧になり、PDFは同じページに留まる。
2. しおり一覧から「メール一覧へ」を押すと元のメール一覧へ戻れる。
3. 別タブの表示モードは変わらない。

### Edge Cases

- しおりがない場合は空のしおり一覧を表示する。
- 切り替え先の読み込みに失敗した場合は元の表示を保つ。

## Requirements

- FR-001: 一覧上部に現在の表示モードから別の表示モードへ切り替えるボタンを置く。
- FR-002: 切り替えは現在のPDFとタブ位置、表示ページを維持する。
- FR-003: メールの既読状態を含む既存のインデックスを、しおり表示への切り替えで失わない。
- FR-004: 元PDFを書き換えない。

## Success Criteria

- SC-001: 利用者はボタン1回で両モード間を切り替えられる。
- SC-002: 切り替え後も表示ページと他のタブの状態が維持される。

## Assumptions

- 手動で選んだモードは、開いているタブの間だけ有効とする。PDFを閉じて再度開くと自動判定に戻る。
