# Implementation Plan: アプリアイコン画像の差し替え

1. 指定PNGを読み、透過領域を除いた図柄の外接矩形を求める。
2. 図柄を中央に置いた透過正方形を作り、複数サイズを含むICOとして既存パスに保存する。
3. ICOのサイズ、透明度、縮小時の視認性を確認する。
4. Python実行時のQtアイコンテストと既存テストを実行する。Nuitka・WiX・VirusTotal・VERSIONとタグの参照関係を静的確認する。ユーザーの指示に従いローカルNuitkaビルドは実行しない。

元PNG、PDF、SQLite、設定ファイルは変更しない。既存のICOのみ差し替える。
