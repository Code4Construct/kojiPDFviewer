# Feature Specification: しおり階層の展開数

**Created**: 2026-09-26
**Status**: Approved for implementation
**Input**: しおり一覧に「＋ 数字 −」を表示し、展開する階層を1段ずつ変える。最上位は1、その直下は2。PDFを開いたときは折りたたんだ状態を既定とする。

## User Scenarios & Testing

### User Story 1 - 階層を段階的に表示 (Priority: P1)

利用者は、しおり一覧上部で表示階層を1から最大階層まで増減できる。

**Acceptance Scenarios**:

1. PDFを開くと数字は1で最上位のしおりだけが表示される。
2. ＋を押すと数字が2になり、その直下のしおりまで表示される。−を押すと1へ戻る。
3. 最小値と最大値では該当ボタンを押せない。
4. 「全展開」は最大階層、「全折り」は1に設定する。

### User Story 2 - 閲覧状態の維持 (Priority: P2)

階層の変更はPDFの表示ページを変えず、タブごとに独立する。検索中は階層操作を無効にし、検索を終えると元の階層に戻る。

**Acceptance Scenarios**:

1. ＋・−・一括ボタンでは表示ページが変わらない。
2. 検索中は「＋ 数字 −」と一括ボタンが無効になり、検索解除で元の階層数に戻る。
3. PDF側でページを変えても設定された階層数は維持される。

### Edge Cases

- しおりがない場合は数字0で操作を無効にする。
- 個別のしおりを手動展開しても数字は設定値のままにし、次の階層操作で設定値に従う表示へ揃える。

## Requirements

- FR-001: しおり一覧上部に＋・数字・−を置く。
- FR-002: 1始まりの階層数でツリーを展開し、既定値は1とする。
- FR-003: 既存の一括操作と検索、ページ移動に整合させる。
- FR-004: PDF、インデックス、アプリ設定を変更しない。

## Success Criteria

- SC-001: 3階層以上の合成PDFで、1・2・3・最大階層の表示を確認できる。
- SC-002: 階層ボタンを押しても表示ページが維持され、検索解除後は元の階層数に戻る。
