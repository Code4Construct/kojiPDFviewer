# Implementation Plan: しおり階層の展開数

**Date**: 2026-09-26 | **Spec**: [spec.md](spec.md)

## Summary

`main.py` の `DocumentPdfTab` にタブ単位の表示階層数を持たせる。既存の一覧上部に＋・数値・−を置き、一括ボタンと同じ状態を更新する。ツリー再表示時は階層数に従って展開する。検索中はフラット一覧なので操作を無効にする。

## Compatibility

しおりのデータ、PDF、SQLite、アプリ設定は変更しない。ページ追従は折りたたみ状態を破らないよう、表示できる最も深い祖先しおりを選択する。個別の手動展開は可能だが、数値は一括表示の設定値を示す。

## Verification

一時フォルダの合成PDFで階層1〜最大、一括操作、検索と解除、タブ独立、PDFページ維持、ページ追従をGUIテストで確認する。検証後に `docs/日本語仕様書.md` を更新する。

実施結果: 合成PDFのオフスクリーンGUIで階層1〜3、＋・−、一括操作、検索中の無効化と復帰、PDFページ維持、ページ追従、別タブの初期値、しおりなしPDFを確認。実際のKojiPDF生成PDFでの目視確認は未実施。

## Constitution Check

既存のPDF閲覧・検索・しおり移動を維持し、日本語をUTF-8で扱う。実際のPDFはGitへ含めない。
